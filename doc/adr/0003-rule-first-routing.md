# ADR-0003: 라우팅은 규칙이 먼저 판단하고, 규칙이 못 정할 때만 LLM이 분류한다

- 상태: Accepted
- 관련: `src/finagent/slots.py`, `graph/nodes.py::route_node`

## 배경
베이스라인은 모든 질문에 문서 5개를 넣어 LLM을 1회 호출한다(질문당 프롬프트 3,188토큰). 인사에도 검색을 한다.
질문을 chat / out_of_scope / easy(단일 사실) / hard(비교·계산)로 나눠, 쉬운 질문은 바로 답하고 어려운 질문만 계획·도구·검증을 거치게 한다.

## 결정
슬롯 추출(상품 종류, 은행, 상품명, 금액, 기간, 신용점수)과 신호어(비교어·계산어)로 규칙을 먼저 적용한다. 결정하지 못한 질문만 LLM이 `RouteOutput`으로 분류한다.
금액·기간은 결정론 파서로 뽑는다(`5조 8000억`, `2년 반`).

## 대안 비교
| 대안 | 장점 | 단점 |
|---|---|---|
| A. 항상 LLM 분류 | 표현 변화에 유연 | 질문마다 LLM 1회 추가, 결과가 흔들림 |
| **B. 규칙 우선 + LLM 폴백 (채택)** | 재현 가능, 지연 0, 정확도를 측정할 수 있음 | 규칙에 없는 표현은 LLM으로 넘어감, 규칙 과적합 위험 |

## 근거(실측)
- 소형 모델의 슬롯 추출 정확도: qwen3.5:2b 0/8, qwen3:8b 7/8. 금액은 8b도 틀린 사례가 있어 파서로 처리한다.
- 라우팅 세트 20문항(규칙 작성 전에 먼저 작성): 첫 측정 **18/20**. 틀린 원인은 "SC제일은행"의 '제일'을 비교어로 인식한 것, 대출 동사 누락, 같은 이름 상품 2개를 비교로 셈. 고친 뒤 20/20(이 수치는 더 이상 홀드아웃이 아니다).

## 결과·트레이드오프
- 잡담·범위 밖 질문은 LLM 1회 또는 0회로 끝난다.
- 규칙은 사람이 만든 목록이라 새 표현에 약하다. 홀드아웃 첫 측정치(18/20)를 한계로 보고한다.

## 재검토 조건
LLM 폴백 비율이 높아지거나 라우팅 오분류가 정답률을 끌어내리면 A 또는 분류용 소형 모델 미세조정을 검토한다.
