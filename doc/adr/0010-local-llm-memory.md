# ADR-0010: 로컬 qwen3:8b를 기본 LLM으로 쓰고 문맥 길이를 8,192로 제한한다

- 상태: Accepted
- 관련: `src/finagent/config.py`, `llm.py`, `.env.example`

## 배경
개발 노트북은 16GB다. 비용 없이 반복 측정하려면 로컬 모델이 필요하다. OpenAI는 선택 백엔드로 둔다.

## 결정
- 기본은 Ollama `qwen3:8b`(think=false, temperature 0), `num_ctx=8192`로 한다.
- `LLM_BACKEND=openai`이면 OpenAI 호환 API를 쓴다(키가 없으면 명확한 오류로 멈춤).
- 프롬프트가 `num_ctx`에 닿으면 조용히 잘리지 않고 오류로 멈춘다.

## 근거(실측)
- `num_ctx=16384`일 때 Ollama가 7.4GB를 차지해 노트북이 끊겼다. 실측 최대 프롬프트는 약 3,500토큰이라 8,192로 줄였다.
- 베이스라인 지연 중앙값: 이전 측정 약 20초 → 8,192에서 11.3초(메모리 압박 감소 효과 포함).
- 소형 모델(qwen3.5:2b)은 조건 추출 0/8로 쓸 수 없었다.

## 대안 비교
| 대안 | 장점 | 단점 |
|---|---|---|
| **A. 로컬 8B (채택)** | 비용 0, 데이터 외부 전송 없음 | 느림, 구조화 출력에 민감, 메모리 부담 |
| B. OpenAI | 빠르고 정확 | 과금, 질문이 외부로 전송됨 |

## 재검토 조건
발표·데모처럼 응답 속도가 중요하면 `LLM_BACKEND=openai`로 같은 골든셋을 측정해 비교한다.
