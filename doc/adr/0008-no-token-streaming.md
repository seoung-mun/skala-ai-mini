# ADR-0008: 답변 토큰은 스트리밍하지 않고, 진행 단계만 보낸 뒤 검증된 답을 한 번에 보낸다

- 상태: Accepted
- 관련: `src/finagent/server.py`, `doc/API_CONTRACT.md`

## 배경
베이스는 답변 토큰을 SSE로 즉시 흘려보낸다. v2는 답을 검증한 뒤 반려·재작성할 수 있다. 토큰을 먼저 보내면 사용자가 틀린 숫자를 본 뒤 답이 바뀐다.

## 결정
SSE로는 `RouteDecided`, `PlanCreated`, `TaskCompleted`, `ReplanCheck`, `Validation` 같은 진행 이벤트만 보낸다. 검증된 답은 `FinalAnswer` 1회로 보낸다.

## 대안 비교
| 대안 | 장점 | 단점 |
|---|---|---|
| A. 토큰 스트리밍 | 첫 글자가 빨리 보임 | 검증 전 문장이 노출되고 재작성 시 화면이 바뀜 |
| **B. 단계 이벤트 + 최종 1회 (채택)** | 사용자는 검증된 답만 봄, 진행 상황은 보임 | 첫 글자까지 기다리는 시간이 김 |

## 재검토 조건
검증 실패율이 매우 낮아지면 "검증 중" 표시와 함께 토큰 스트리밍을 다시 검토한다.
